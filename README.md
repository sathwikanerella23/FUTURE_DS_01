# 📊 Business Sales Performance Analysis

## 📌 Overview

This project analyzes sales data to identify business insights such as revenue trends, top categories, and regional performance.

---

## 🛠 Tools Used

- Python
- Pandas
- Matplotlib
- Google Colab

---

## 📈 Analysis

- Total Sales Analysis
- Sales by Category
- Profit by Region
- Monthly Trends

---

## 🔍 Insights

- Electronics category generated the highest sales.
- Laptop and Phone are top-selling products.
- South region showed strong performance.
- Sales varied across different dates.

---

## ✅ Recommendations

- Focus more on high-performing products.
- Improve strategies in low-performing regions.
- Promote top-selling products.
- Analyze trends regularly.
